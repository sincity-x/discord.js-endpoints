# Discord Multi-Bot-Inspired Dashboard


A modern Discord control panel with a **Multi-bot-inspired UI**, while using an official Discord bots for authentication.

## Features

- Bot token authentication = NEEDED BOT TOKEN 
- Bot status
- Server listing - `DISCORD_BOT_TOKEN`
- Refresh controls
- Bot-to-user DMs
- Connection-request style interface
- Responsive dashboard

## Setup

1. Install Node.js.
2. Copy `.env.example` to `.env`.
3. Put your bot token in `DISCORD_BOT_TOKEN`.
4. Run:

```bash
npm install
npm start
